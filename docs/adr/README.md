# Architecture Decision Records

An ADR records one architectural decision: the context, the options, what was chosen and why. ADRs are never deleted or rewritten after they are accepted; a changed decision gets a new ADR that supersedes the old one.

## How to add one

1. Copy `template.md` to `NNNN-short-title.md`, using the next free number (`0001`, `0002`, ...).
2. Fill it in with status `Proposed` and open a PR.
3. Set the status to `Accepted` when the PR is merged, and add it to the index below.
